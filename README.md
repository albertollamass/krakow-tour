# krakow-tour · Cracovia 26–29 octubre 2026 🇵🇱

Guía interactiva de viaje publicada con GitHub Pages.

- `index.html` → web completa (itinerario + mapa Leaflet/OpenStreetMap en vivo + rutas a Google Maps + checklist con localStorage + cuenta atrás)
- Sin build: un solo HTML estático, ideal para Pages.

## Ver en local
Abre `index.html` en el navegador. Para geolocalización usa `https` o `localhost`.

## Despliegue (GitHub Pages)
1. Crear repo vacío en GitHub (sin README).
2. `git remote add origin <URL> && git push -u origin main`
3. En GitHub: Settings → Pages → Deploy from branch → `main` / `/ (root)` → Save.
4. URL: `https://<usuario>.github.io/<repo>/`
